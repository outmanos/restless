# 0.2.0 migration design

Goal: an Insomnia, Insomnium or Bruno user moves over in one click and sees exactly what moved.

## Rules

- Never write to the source. Not its files, its folder or its lock.
- No network. Migration runs offline. Reinstalling plugins is a separate click.
- Re-running is safe. Existing documents are skipped, never overwritten.
- Nothing is dropped silently. Every skipped item appears in the report.
- Reports never contain secret values.

## Shape

Every source produces the same plan. One writer commits it.

```
detect -> read -> plan -> (user reviews) -> commit -> report
```

New code lives in `packages/insomnia/src/main/migration/`:

| File | Purpose |
|---|---|
| `types.ts` | The shared contract below |
| `detect.ts` | Find installs on this machine |
| `insomnia/read-log.ts` | Replay NeDB files without NeDB |
| `insomnia/plan.ts` | Turn Insomnia documents into a plan |
| `bruno/read.ts` | Parse `.bru` and YAML collections |
| `bruno/plan.ts` | Turn a Bruno collection into a plan |
| `bruno/translate-script.ts` | Script translation |
| `commit.ts` | Write a plan and build the report |
| `ipc.ts` | `migrationDetect`, `migrationPlanInsomnia`, `migrationPlanBruno`, `migrationCommit` |

UI lives in `packages/insomnia/src/ui/components/migration/`.

## Contract

```ts
export type SourceKind = 'insomnia' | 'insomnium' | 'bruno';

export interface DetectedSource {
  id: string; // Stable: kind plus path
  kind: SourceKind;
  path: string;
  counts: { projects: number; collections: number; requests: number; environments: number };
  running: boolean; // A lock or recent write suggests the app is open
}

export interface PlanItem {
  type: string; // Model type
  name: string;
  doc: Record<string, unknown>; // Plain document, not yet through initModel
}

export type ReportReason =
  | 'already-imported'
  | 'secret-not-readable'
  | 'cloud-only'
  | 'git-project'
  | 'file-missing'
  | 'unknown-model'
  | 'not-supported'
  | 'script-partly-translated'
  | 'parse-error';

export interface ReportEntry {
  reason: ReportReason;
  type: string;
  name: string;
  detail?: string; // Never a secret value
}

export interface MigrationPlan {
  source: DetectedSource;
  items: PlanItem[]; // Parents before children
  issues: ReportEntry[]; // Known before writing
  plugins: string[]; // Package names found, for the plugin step
}

export interface MigrationReport {
  source: DetectedSource;
  startedAt: string;
  finishedAt: string;
  imported: Record<string, number>; // By model type
  entries: ReportEntry[]; // plan.issues plus commit results
}
```

## Detect

Search each platform's app data folder for `Insomnia` and `Insomnium`. A folder counts if it has `insomnia.Workspace.db`.

Also check the Flatpak and snap paths, and verify them first. Never list restless's own folder or the dev folder `insomnia-app`.

Bruno has no central data folder. The user picks a collection folder or a parent of many. A folder is a collection if it has `bruno.json` or `opencollection.yml`.

## Insomnia

### Reading

Do not open the files with NeDB. It compacts on load, which rewrites the file.

`read-log.ts` opens each `.db` read-only and replays it: each line is a document, a later line with the same `_id` replaces it, `$$deleted` removes it, and `$$indexCreated` is ignored. A torn final line is dropped and reported, since the app may be running.

### What moves

| Handling | Models |
|---|---|
| Import | Project, Workspace, WorkspaceMeta, Environment, CookieJar, RequestGroup, RequestGroupMeta, Request, RequestMeta, GrpcRequest, GrpcRequestMeta, WebSocketRequest, WebSocketPayload, SocketIO and MCP request models and their payloads, ApiSpec, MockServer, MockRoute, ProtoDirectory, ProtoFile, UnitTestSuite, UnitTest, ClientCertificate, CaCertificate, PluginData |
| Skip, report | GitRepository (`git-project`), GitCredentials, CloudCredential, OAuth2Token (`secret-not-readable`), unknown types (`unknown-model`) |
| Skip quietly | Settings, Stats, UserSession, responses and their files, RequestVersion, UnitTestResult |

Quiet skips are listed once in the report footer, not per item.

### Mapping

- IDs are kept. References stay valid and `already-imported` works by `_id`.
- If a kept ID is reserved by restless, such as a scratchpad document, give it a new ID and apply `models.rewriteReferences`.
- Every Project gets `parentId: 'org_local'` and loses `remoteId`. All become local projects.
- One restless project per source project. On a name clash, append ` (Insomnia)` or ` (Insomnium)`.
- A cloud project with no local documents gets a `cloud-only` entry.
- A Git project gets a `git-project` entry with its folder, and advice to use `File > Open Folder…`.
- `__insomnia_vault` values and `secret` environment entries are encrypted with a key we don't have. Keep the key name, clear the value, report `secret-not-readable`.
- Certificates keep their file paths. A missing file gets a `file-missing` entry.

## Bruno

### Reading

`.bru` files use `@usebruno/lang` (MIT, small), pinned. Keep its MIT notice with the app's other third-party licenses. Do not use `@usebruno/converters`, which pulls in `jscodeshift`.

YAML collections are parsed with the `yaml` dependency we already have. Verify the OpenCollection layout against a collection made with Bruno itself, not against third-party guides.

### Mapping

| Bruno | restless |
|---|---|
| Collection | Workspace in a new project named after the source |
| Folder, `folder.bru` | RequestGroup with its headers, auth and scripts |
| `collection.bru` with settings | A root RequestGroup holding them, otherwise no wrapper |
| HTTP, GraphQL, gRPC, WebSocket request | The matching model |
| `seq` | `metaSortKey` |
| `script:pre-request` | `preRequestScript` |
| `script:post-response`, `tests` | `afterResponseScript`, in that order |
| `vars:pre-request` | Prepended `insomnia.variables.set` lines |
| `assert` | Generated `insomnia.test` lines, or `not-supported` if the operator has no match |
| `docs` | `description` |
| `environments/*` | Sub environments |
| `vars:secret` | Key with an empty value, `secret-not-readable` |
| `{{var}}` | `{{ _.var }}` |
| `{{process.env.X}}` | Left as text, reported |

### Scripts

`translate-script.ts` follows `translate-postman-script.ts`: an ordered rule table, tested per rule. It covers `bru.getEnvVar`, `bru.setEnvVar`, `bru.getVar`, `bru.setVar`, `req.*`, `res.*`, `test()` and `expect()`.

After translating, scan for leftover `bru.`, `req.`, `res.` and `require(`. If any remain, comment out the original at the top of the script and report `script-partly-translated`. A script must never look translated when it isn't.

## Commit

`commit.ts` takes a plan and:

1. Takes a restless backup with `main/backup.ts`, before the first write.
2. Skips any `_id` that already exists, recording `already-imported`.
3. Passes each doc through `initModel`, which applies schema migrations for old documents.
4. Inserts in plan order between `database.bufferChangesIndefinitely()` and `flushChanges()`.
5. Records a failed document as `parse-error` and continues.
6. Saves the report to `<data>/migrations/<timestamp>.json` and returns it.

## UI

- **Entry:** `File > Migrate from…`, plus a button in the import modal.
- **Step 1:** detected installs with counts, and a folder picker for Bruno. Warn if `running` is true.
- **Step 2:** what will move and what won't, from the plan.
- **Step 3:** the report: counts, then grouped entries with a way to copy them.
- **First launch:** if detect finds something, offer migration once, in onboarding. Declining is remembered in Settings. Detection reads local files only.
- **Plugins:** after the report, list plugins found, each with its own install click. This is the only step that uses the network.

## Testing

- Fixtures are generated by a script, never copied from a real install.
- Every test that reads a source hashes it before and after. A changed hash fails the test.
- Cover torn final lines, deleted documents, old document versions, and running the same import twice.
- Bruno fixtures come from real collections made in Bruno, for both `.bru` and YAML.
- One smoke test runs a full migration from a seeded folder.

## Tasks

Written to run in parallel. `types.ts` lands first, so no task edits another's files.

| Task | Owns | Roadmap items |
|---|---|---|
| 0. Contract | `types.ts`, `ipc.ts`, stubs | None (me, first) |
| 1. Insomnia source | `detect.ts`, `insomnia/*` | Detect, list contents, never change the source |
| 2. Commit | `commit.ts` | One-click import, report data |
| 3. Bruno source | `bruno/*` | Bruno import, script translation, bulk import |
| 4. UI | `ui/components/migration/*`, menu, onboarding | Report view, first-launch offer, plugin reinstall |
| 5. Finish | Smoke test, `docs/wiki/Migration.md`, Roadmap | None (me, last) |

The Postman workspace dump is P2 and stays out unless time allows. `getFilesFromPostmanExportedDataDump` already covers most of it.

## Decisions

1. Keep source IDs instead of generating new ones. Recommended, since it makes re-runs safe.
2. Add `@usebruno/lang` as a dependency instead of porting the parser. Recommended, since it tracks Bruno's format.
3. Leave Git projects out of the migration and point to `File > Open Folder…`. Recommended, since copying a repository out of another app's folder is fragile.
4. Do not import Settings. Recommended for 0.2.0, since a bad setting is hard to trace.
