# Privacy

restless has no accounts and no telemetry.

## When restless uses the network

| Action | Goes to |
|---|---|
| Sending a request | The server you chose |
| Git fetch, pull or push | Your Git remote |
| Update check | GitHub Releases, only if you turn on **Automatic updates** or check by hand |
| Installing a plugin | npm |
| Sign-in, AI and secret managers | The provider you set up, only after you turn them on |

Unless you allow automatic updates, starting restless makes no requests.

## What stays local

Collections, environments, history, cookies and tokens are stored on your machine. Vault keys are generated locally.
